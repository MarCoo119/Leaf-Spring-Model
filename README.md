# Leaf Spring CAD Model

## 📌 Overview
This repository contains a parametric leaf spring CAD model representing a suspension component commonly used in automobiles and heavy vehicles. The project focuses on accurate geometry, assembly structure, and functional representation suitable for engineering visualization and study.

---

## 🛠️ Features

- Multi-leaf spring assembly (master leaf + graduated leaves)
- Accurate arc profile and thickness variation
- Center bolt and clamp representation
- Fully constrained parametric design
- Clean geometry suitable for analysis and visualization

---

## 📂 Contents

- Individual leaf spring part files
- Assembled leaf spring model
- Simplified structure for easy understanding

---

## 🎯 Purpose

- Understanding automotive suspension components
- CAD practice and assembly modeling
- Academic mechanical design projects
- Engineering portfolio demonstration

---

## 🧰 Tools & Software

- Siemens NX
- Parametric sketching and assembly modeling tools
